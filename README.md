# Clickable Mail

Внутренний конструктор писем: письмо собирается из блоков (компоненты из Figma-файла Mail-Autocode), настраивается и выгружается в HTML/ZIP.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в dist/
```

## Устройство

- `src/model` — модель письма (`types.ts`), каталог блоков, клиенты, шаблоны, пресеты (`catalog.ts`).
- `src/store` — состояние редактора с историей (zustand + zundo), UI-состояние, черновики в IndexedDB (временная замена бэка).
- `src/email` — рендер письма в HTML. Один и тот же HTML идёт в превью (iframe) и в экспорт.
  Сейчас разметка блоков схематичная; на этапе переноса компонентов из Figma `blocks.ts` заменится на табличную вёрстку.
- `src/editor` — экран редактора: библиотека, холст с оверлеем, слои, инспектор, экспорт.
- `src/home` — стартовый экран: клиент → шаблон, черновики.
- `src/ui` — общие контролы.
