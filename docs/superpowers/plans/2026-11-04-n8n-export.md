# Экспорт через n8n в формате плагина v5 — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** приложение строит `plan` v5 и картинки, шлёт JSON плагинного формата в новую автоматизацию n8n и экспортирует вернувшийся HTML (ZIP, HTML, Код).

**Architecture:** письмо рендерится в скрытом iframe 600px; планировщик обходит DOM (модель блока + `data-plan`-подсказки в рендерах) и строит элементы плана; растеризатор снимает картинки 2× через SVG foreignObject → canvas. Payload уходит на вебхук; воркфлоу `n8n/clickable-mail.json` проверяет имена, заливает картинки по FTP, запускает копию генератора `html_gen` v5 и отвечает JSON с HTML. Окно экспорта кэширует результат по версии письма.

**Tech Stack:** React 19, TypeScript 7, Vite 8, zustand, JSZip; Vitest 5 (проекты `unit` — node, `browser` — Playwright Chromium); n8n (узлы тех же версий, что в плагинном воркфлоу); Node 24 для CLI-скриптов (`.ts` запускаются напрямую).

**Spec:** `docs/superpowers/specs/2026-11-04-n8n-export-design.md`

### Task 2: Воркфлоу `n8n/clickable-mail.json`

**Files:**
- Create: `n8n/clickable-mail.json`, `n8n/workflow.test.ts`, `n8n/README.md`

**Interfaces:**
- Consumes: `nodeCode`, `patchForApp`, `runCode` (задача 1).
- Produces: ответ вебхука — `{ ok: true, html: string, kb: number, images: { file: string; url: string }[] }` или `{ ok: false, error: string }` (всегда HTTP 200).

Узлы (имена точные; типы и версии — как в плагинном JSON: webhook 2.1, code 2, if 2.3, ftp 1, aggregate 1; respondToWebhook 1.1):

| Узел | Что |
|---|---|
| `Webhook` | POST, `path` — новый uuid v4, `responseMode: 'responseNode'`, `options.allowedOrigins: '*'` |
| `Подготовка картинок` | Code, all items: проверка запроса и картинки → элементы `{ json: { kind, ftpName?, error? }, binary?: { data } }` |
| `Ошибка в запросе?` | If: `kind == 'error'` → `Ошибка`, иначе → `Есть картинки?` |
| `Есть картинки?` | If: `kind == 'image'` → `FTP`, иначе → `html_gen` |
| `FTP` | upload, `path: '=/public_html/email_images/{{ $json.ftpName }}'`, credentials `{ ftp: { id: 'k2Er5gljEUnhmCRt', name: 'FTP account' } }`, `onError: 'continueErrorOutput'` (ошибка → `Ошибка`) |
| `Все загружены` | Aggregate, aggregateAllItemData → `html_gen` |
| `html_gen` | Code = `patchForApp(снимок)`, `onError: 'continueErrorOutput'` → `Ошибка` |
| `Ответ` | Code: `{ ok: true, html, kb, images }` |
| `Отправить ответ` / `Отправить ошибку` | Respond to Webhook, `respondWith: 'firstIncomingItem'`, `options.responseHeaders.entries: [{ name: 'Access-Control-Allow-Origin', value: '*' }]` |
| `Ошибка` | Code: `{ ok: false, error }` из `$json.error` (строка или `.message`) |

Проверки в `Подготовка картинок` (сообщения по-русски): `imageNodes` — массив ≤ 60; `folder` ~ `^cm(/[A-Za-z0-9_-][A-Za-z0-9._-]*)+$`, без сегмента `..`; `file` ~ `^[A-Za-z0-9_-][A-Za-z0-9._-]*\.(png|jpe?g|gif)$`, без `..`; декодированный размер ≤ 5 МБ. mime — по расширению. `ftpName = folder.split('/').join('--') + '--' + file`. Нет картинок → один элемент `{ kind: 'none' }`; любая ошибка → один элемент `{ kind: 'error', error }`.

### Task 6: Планировщик — общий обход DOM

**Files:**
- Create: `src/email/plan/planner.ts`, `src/email/plan/planner.browser.test.ts`

**Interfaces:**
- Consumes: `Frame`, `relRect`, `RasterMode`, `shadowRect` (5); `textStyle`, `styleDiff`, `normColor` (4); `normLink`, `slug` (3); типы (3).

  - `interface Draft { body: StackItem; shots: ShotRequest[]; warnings: Plan['warnings'] }`
  - `planBody(f: Frame, doc: EmailDoc): Draft`

Алгоритм (`walk(el)` → `PlanItem | null`), по порядку:
1. Невидимое (display none, visibility hidden, нулевая рамка) и `.e-bgl` — пропустить.
2. Подсказка `data-plan` — задача 7 (здесь — точка расширения: `switch` по значению).
3. `<img>`, `svg`, `.e-ph` → `ImgItem`, снимок `whole`, база — `data-plan-name` | `slug(alt)` | `img`; `.e-ph` → ещё предупреждение «В блоке «<название из каталога>» не загружена картинка».
4. Есть потомок `position: absolute|fixed` → весь элемент `ImgItem` (`whole`, база `block`) + предупреждение «… собран картинкой: элементы накладываются».
5. Текстовый бокс (прямой текст или все видимые дети строчные/`<br>` — как `isTextBox` в `mailExport.ts`) → `TextItem`: `st = textStyle(el)`; `runs` — обход текстовых узлов: текст со схлопнутыми пробелами, `d = styleDiff(st, textStyle(родитель узла))`, `ln = normLink(href ближайшего <a>)` или нет; `<br>` → `\n`; соседние прогоны с одинаковыми `d`/`ln` склеить; края обрезать. `ta` из `text-align` (`start` → `left`, `end` → `right`); `wrap = display` не `inline*`; `lines` = число строк по `\n`. Цвета — относительно `doc.theme.bg`.
6. Иначе `inner` = раскладка видимых детей: дети → `walk`; строки по перекрытию по вертикали (как в `compile` `mailExport.ts`); наложение по горизонтали внутри строки → весь элемент картинкой (п. 4); одна строка из нескольких → `RowItem` (`va` из `align-items`: center → middle, flex-end → bottom, иначе top); несколько строк → `StackItem` (`ca`: flex-column + `align-items: flex-start` → `MIN`, `flex-end` → `MAX`); один элемент — он сам.
7. Своя отрисовка (`paintKind`): `none` — нет фона/рамки; `css` — сплошной `background-color` и/или сплошная рамка, скругление; `image` — градиент/картинка в фоне, маска, `clip-path`, `transform`, `filter`, `box-shadow`, непустой `::before/::after`, рамка не `solid`. `none` → `inner`; `css` → `BoxItem { fill, border, r, content: inner }`; `image` → `BoxItem { bg: снимок 'own' (база 'block'), content: inner }`. Лист без детей и текста: `none` → пропуск, `css` → `BoxItem` без содержимого, `image` → `ImgItem` (`whole`).
8. Корень: каждый `.em-blk` → `walk`; у элементов `id` = `<blockId>:<n>`; верхний `StackItem` без своей отрисовки разворачивается в `body.items` (как `rootKids` у плагина). `body = { k: 'stack', id: 'body', x: 0, y: 0, w: 600, h: высота письма, items }`.

`fill`/`border.c` — `normColor` относительно фона письма; `border.w` — 4 стороны; `r` — число, если углы равны, иначе кортеж (проценты пересчитать от рамки).
